# Moect 使用指南

## 安装与升级

从 [Releases](https://github.com/mofan6/Moect/releases/latest) 下载对应版本的 `Moect-版本号-Setup-x64.exe`，双击后选择安装位置，并勾选是否创建桌面快捷方式，再点击“安装”。软件默认安装在当前用户的 `%LOCALAPPDATA%\Programs\Moect`，可自行更改，无需预装 Python 或 Node.js。缺少 WebView2 时，安装器通过 Microsoft 官方引导程序自动安装，需要网络连接。

升级前请等待导出任务完成并关闭 Moect。覆盖安装保留用户配置、聊天快照、媒体缓存及历史任务。卸载只移除软件，不删除这些数据或聊天导出。

便携压缩包可解压后运行 `Moect.exe`，保留同级 `_internal` 文件夹。包内不附带使用说明和修复说明，需要时可在项目首页或源码中查看。

## 连接与预览

先登录 Windows 微信，再点击“连接微信”。选择账号后，Moect 获取本地读取凭据，整理聊天快照，并显示好友和群聊。微信版本或进程权限不同可能影响连接；确有权限不足提示时，可退出软件后以管理员身份启动。

也可在设置中打开已有解密备份。演示模式使用完全虚构的记录，便于先了解界面。

首次入门教程所在的这轮启动不会自动连接，即使本机留有旧账号缓存；看完教程也不会补发自动连接，需要自行点击“连接微信”。之后启动 Moect 时，若曾成功连接过微信，会自动尝试重新连接并整理上次的账号，更新聊天快照；微信未打开或未登录时会在右下角提示。教程展示或重播期间，悬浮提示不会覆盖教程按钮，点击外部提示也不会关闭教程。点击左上角账号，在连接弹窗的账号右侧点击“退出登录”，会清空当前会话和概览，保留任务记录、导出文件及本地快照，并停止后续启动时的自动重连，直到再次手动连接。

点击整行会话直接进入预览，右侧“导出”按钮可创建任务。“批量选择”用于同时导出多个会话。

## 表情包与朋友圈

左侧“表情包”可按收藏、自定义表情和已安装专辑批量导出；可选择仅处理本机已有资源，或尝试补充下载。动画保持为 GIF/WebP，WXGF 动画转换为 GIF。只有缩略图的条目会明确标注，未恢复的原图会在资源明细中记录。

朋友圈打开后即可预览和导出本地已缓存的动态，时间范围为可选项。请自行在微信浏览和缓存新内容，再点击右上角“刷新资源快照”更新列表；软件不会模拟鼠标、自动浏览朋友圈或主动下载朋友圈内容。点赞与评论随归档保存，可分别展开或收起，点击点赞头像查看姓名。

聊天记录或语音没有更新时，使用“重新连接并整理”；朋友圈和表情包列表没有更新时，使用“刷新资源快照”。“恢复图片读取”用于重新获取并校验当前账号的图片读取材料，不会下载未缓存的原图，也不替代刷新聊天或资源数据库。点击后会显示操作提示：先在微信打开一张近期原图，确认需要的图片已在本机缓存，再开始恢复；可选择不再提示。

## 收藏导出（测试）

先在电脑微信打开收藏及需要的附件，再到 Moect 左侧“收藏（测试）”页面刷新资源快照。首次未取得收藏库读取凭据时，请打开微信收藏后重新连接并整理微信。

收藏支持按类型、日期和关键词筛选，预览后可选择或批量导出。每次导出包含 HTML、逐条 Markdown、JSON 和可读取的附件；文章正文可选联网读取。移动归档或导入笔记软件时，请带上整个文件夹。详见 [收藏导出](favorites.md)。

## 外观与系统

设置里可直接选择原有鸢尾紫及新增的晴空蓝、青瓷青、松叶绿、暖杏橙、蔷薇粉、朱砂红、雾山灰，支持浅色/深色，自动记忆到下次启动。

当前桌面版面向 Windows 10 1809 x64 及以上和 Windows 11。Win7 不能通过修改安装位置或兼容模式运行当前 Python/WebView2 组合，参见 [Windows 兼容性调查](windows-compatibility.md)。

## 导出与阅读

支持 HTML / JSON / JSONL / TXT / CSV / Markdown / Excel，可选择导出时间和关键词。

新任务的外层目录按“昵称_UID_日期时间”命名，同名时增加数字后缀。已有导出目录与任务路径不自动重命名，避免破坏既有链接。

导出内容可选择：包含系统消息、快速导出、不导出图片/动画表情、不导出视频、不导出语音、仅保留文件元数据以及导出头像。

快速导出保留消息和卡片信息，跳过所有资源与头像。单项资源开关同样阻止本地文件复制、网络下载、解密和转码，适合视频较多或磁盘空间有限的会话。跳过图片也会跳过卡片缩略图，头像由单独开关控制。设置会继续作用于转发和引用；主动跳过的资源有单独状态，不计为缺失或失败。

HTML 打开后直接进入聊天记录，不再经过归档目录页。批量 HTML 导出在聊天页顶部提供会话切换。顶栏右下角箭头可收起或展开顶栏，筛选条件会保留。短消息气泡随内容收紧，长链接在气泡内换行。查看器支持关键词和发送者搜索、北京时间起止时间筛选及“显示全部”；只能筛选本次已导出的消息。

图片和表情点击本身即可查看；分享卡片展示可用标题、说明、缩略图及来源。已保存的文件可从卡片下载。转账卡片只展示历史消息中的金额和状态，不提供支付操作。合并转发会生成独立 HTML 页及 JSON、TXT 副本。

图片、动画表情和语音气泡不再重复显示类型占位词。语音在本机自动从 SILK 转换为可直接播放的 WAV，并随归档保存；转换失败时会保留原文件和具体状态。选择“不导出语音”或“快速导出”时不会读取或转换语音。既有 HTML 需要重新导出才会使用这些改动。

**移动或分享归档时，请复制完整导出文件夹。** HTML 依赖消息分片和本地资源，单独移动 HTML 会导致媒体或消息缺失。撤回等系统消息显示为居中小字，不显示头像和普通消息气泡。新版查看器只用于新导出，已有文件不会被自动重写。

## 资源缺失

导出页顶部会列出已保存、缺失、未解密、不支持及校验失败的资源数量，并提供资源明细。原图尚未下载、微信已清理缓存、凭据不可用或远端资源失效时，不能保证恢复完整资源。

## 存储位置

新安装默认使用 `%LOCALAPPDATA%\Moect` 保存配置与快照。如果发现旧版 `%LOCALAPPDATA%\WeChatExporter\config.json`，会继续沿用旧数据目录。默认新导出路径为 `文档\Moect\exports`，自定义位置不变。不要分享读取凭据、密钥文件或解密快照。

会话页顶栏刷新按钮会重新连接并整理当前微信账号。表情页可点击“缓存所选表情资源”补充已知下载地址；缓存不会突破资源有效期或微信访问权限。所有时间筛选共用日历、小时/分钟及“应用并确定”，取消不会更改已应用条件。

设置 → 缓存与存储可迁移缓存、查看占用或清理过期快照。缓存上限有 1 GB、3 GB、5 GB、10 GB、20 GB、不限制六档，默认不限制，选择会记住。下次启动 10 秒后检查，超限时从旧到新清理过期快照和缓存，正在处理任务时延后检查。当前快照、读取凭据及导出文件会保留，因此保留内容本身过大时仍可能超限。说明右侧的小删除按钮可永久隐藏这段提示，不影响清理设置。

## 窗口与浏览偏好

默认窗口为 1080×800（按系统缩放适配并限制在屏幕工作区内），左侧栏宽度为 208。移动或调整窗口后，正常尺寸、位置和最大化状态会记住；下次启动恢复。移除显示器或改变缩放比例时会调整到可见工作区，不保存最小化状态。

会话默认按“最近活跃”降序排列，用户更改排序字段或升降序后会保存到本地配置，下次启动继续使用。各页面滚动条随当前主题色变化。

新导出的会话 HTML 默认定位到最新一页并显示最新记录，页内仍按聊天时间顺序排列。底部常驻数字页码可直接跳转；每组最多 10 个，超过 10 页才显示“上一列 / 下一列”。搜索或时间筛选后，页码按匹配记录重新计算；引用回复的“查看原消息”仍定位到对应消息。已有 HTML 需重新导出。

任务页可按“全部 / 会话 / 朋友圈 / 表情包 / 收藏”分类。多选可删除所选记录，“清空”清理当前分类的记录；导出文件和进行中的任务保留。

新导出的 HTML 会使用创建导出任务时的主题色与浅色/深色模式；合并转发页、朋友圈及表情包归档也一致。已有 HTML 需重新导出。

群聊正文中的发送者账号前缀会依照发送者信息识别并去除；普通文字冒号与私聊内容保留。图片提示未找到通过完整 AES 校验的密钥，表示当前读取材料不足，属于正常的保护性降级；保留加密原文件，不会跳过密钥或图像完整性校验。

## 新手教程与时间选择

1.3.0 重做了入门、朋友圈和表情包教程，从旧版升级后首次启动会自动展示新版入门教程，之后不再自动重复；可在设置中重新播放。朋友圈、表情包和收藏页面各有独立的首次教程记录，需要重看时点击页面右上角的“新手教程”。教程只展示图解和按钮提示，不会替用户操作微信或自动刷新资源。

朋友圈按“在微信自行浏览目标日期／好友或自己的朋友圈 → 回 Moect 刷新资源快照 → 选择范围并导出”三步使用。表情包按“在微信打开收藏或专辑 → 刷新资源快照 → 勾选分类并导出”三步使用。

日期面板的年、月在日历区域居中，通过自定义主题面板选择。小时和分钟使用主题色列表，选好后点“确定时间”，再点“应用并确定”提交整个范围；“取消”保留原有条件。软件和新导出的离线 HTML 共用此控件，既有 HTML 需重新导出。
