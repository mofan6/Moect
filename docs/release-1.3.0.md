# Moect 1.3.0

本次更新新增收藏导出，重做使用教程，并改善媒体读取和缓存管理。

- **收藏导出（测试）**：按类型、日期和关键词筛选、预览收藏，导出 HTML、Markdown、JSON 和可用附件。
- **新版使用教程**：重做软件入门、朋友圈和表情包教程，说明重新连接、刷新资源快照和恢复图片读取各自的用途。旧版升级后首次启动会展示新版入门教程，之后也可手动重播。
- **媒体读取**：优化图片、语音和表情的读取与异常提示，官方骰子、猜拳表情可按实际结果预览和导出。
- **消息识别**：完善群邀请、撤回、拍一拍等系统消息，改善历史群聊的读取。
- **缓存管理**：新增 1 GB、3 GB、5 GB、10 GB、20 GB、不限制六档上限，默认不限制。下次启动 10 秒后检查，超限时从旧到新清理过期快照和缓存；正在处理任务时延后检查。当前快照、读取凭据及导出文件会保留。
- **界面调整**：优化设置、关于、朋友圈和表情包页面的布局、字体及侧栏入口，会话预览中的刷新按钮可重新连接并整理微信。

媒体仍取决于电脑微信已缓存的内容。请先在微信打开需要的原图、播放语音或浏览目标朋友圈，再回到 Moect 更新相应快照；图片无法读取时按提示使用“恢复图片读取”。已导出的文件需要重新导出才能体现本次改进。

## 下载与升级

- **安装版**：下载 `Moect-1.3.0-Setup-x64.exe`，运行安装程序完成升级。
- **便携版**：下载 `Moect-1.3.0-Windows-x64.zip`，完整解压后运行 `Moect.exe`，保留同级 `_internal` 目录。

支持 Windows 10 1809+ / Windows 11，64 位。升级沿用本机已有配置、任务与归档数据。
